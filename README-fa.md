## درباره برنامه

دارویار یک اپلیکیشن اندرویدی برای مدیریت مصرف دارو و نسخه‌های پزشکی است که به کاربران کمک می‌کند برنامه درمانی خود را منظم‌تر دنبال کنند.

این برنامه با تمرکز بر سادگی، سرعت و استفاده آسان طراحی شده و اطلاعات ثبت‌شده توسط کاربر را به‌صورت محلی روی دستگاه مدیریت می‌کند.

## امکانات

* ثبت و مدیریت داروها
* ایجاد برنامه زمانی برای مصرف دارو
* یادآوری زمان مصرف با اعلان
* ثبت و مدیریت نسخه‌های پزشک
* مشاهده برنامه امروز و وعده‌های مصرف
* مدیریت داروهای فعال
* افزودن توضیحات و تصویر برای دارو
* ثبت اطلاعات بیمار
* ویرایش و حذف داروها و نسخه‌ها
* رابط کاربری مدرن و ساده
* پشتیبانی از زبان فارسی و رابط کاربری RTL
* ذخیره اطلاعات به‌صورت محلی
